# organmo Blog Navigation Guide

`medium.com/@organmo` is an Ethereum researcher's blog on Medium. It provides technical analysis and insights on Ethereum protocol topics, ecosystem developments, and blockchain research.

## URL Patterns

- Main page: `https://medium.com/@organmo`
- Individual posts: `https://medium.com/@organmo/{slug}-{id}`

## Search Strategy

### Using WebSearch

Use the `site:medium.com/@organmo` operator combined with topic keywords:

```
site:medium.com/@organmo ethereum
site:medium.com/@organmo EVM
site:medium.com/@organmo protocol
site:medium.com/@organmo EIP
```

Alternatively, search more broadly and include the author:

```
site:medium.com organmo ethereum
```

### Scanning Recent Posts via WebFetch

Fetch the main profile page to see a list of recent post titles:

```
https://medium.com/@organmo
```

The profile page lists published articles with titles and dates. Identify the most relevant article before fetching its full content.

### Fetching a Specific Post

Once you have a URL from search results or the profile page, fetch the full post:

```
https://medium.com/@organmo/{slug}-{id}
```

## When to Use This Source

Use `medium.com/@organmo` when you need:

- Researcher perspectives on Ethereum protocol topics
- Technical analysis and commentary on EIPs and protocol changes
- Alternative viewpoints complementing official sources and Vitalik's writings
- Korean Ethereum ecosystem context and insights

## Citation Format

```
organmo, "Post Title," Medium, Month Year. URL: https://medium.com/@organmo/{slug}
```
